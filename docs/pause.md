# 安全暂停（冻结进程）原理与边界

## 1. 它做了什么

点击实验行末的 `❚❚`（或右键 → 安全暂停）后：

1. 重新抓取一次进程快照，找到实验根进程及其全部子孙进程（worker、dataloader 等）；
2. 通过 ntdll 的 `NtSuspendProcess` 挂起这些进程的所有线程；
3. 在 `data/paused.json` 写入：键、根 PID、创建时间、启动时间、已暂停时长、指纹、文件夹、标题、命令行等；
4. 行末变为 `▶`，状态显示“已暂停”，CPU / GPU 变为 0。

点击 `▶`（或右键 → 继续运行）时，按与挂起相反的顺序调用 `NtResumeProcess`，实验从冻结点继续执行。

## 2. 它没有做什么

这是**操作系统级进程冻结**，不是磁盘 checkpoint：

- 不会把模型权重、优化器状态写到磁盘；
- 不会释放显存、内存、文件句柄、端口或锁；
- 不能跨电脑/重启恢复运行；
- 不能保证对网络/分布式训练安全。

如果实验脚本自身支持 checkpoint，仍然应该保留脚本的 checkpoint 机制。

## 3. 状态与恢复

### 运行中 → 暂停

- UI 先弹出确认框，说明影响；
- 检测到 `torchrun`、`deepspeed`、`mpirun`、`nccl`、`distributed` 等特征时额外警告；
- 暂停失败（权限不足、进程已退出）会回滚状态并提示。

### 暂停中

- 采样线程每次看到该实验仍标记为 paused，不累计空闲时间，不更新 ETA；
- 已运行时间按暂停时刻冻结；
- 如果检测到进程出现明显 CPU 活动（例如被外部工具恢复），连续两个采样周期后自动解除暂停标记。

### 小组件重启

启动时读取 `data/paused.json`，恢复 paused 会话：

- PID + 创建时间必须匹配，避免 PID 复用误判；
- 进程已不存在的记录会被清理；
- 恢复后仍然可以点 `▶` 继续。

### 退出小组件

如果还有暂停中的实验，退出前会弹窗提醒。退出不会自动恢复它们——它们会保持冻结，下次打开小组件可以继续。

## 4. 安全注意事项

- **不要重启电脑或强制结束进程**：内存中的进度会丢；
- **暂停期间仍占显存**：需要腾 GPU 的话，暂停不一定够；
- **分布式训练**：其它节点可能等待超时，暂停前先确认；
- **文件锁**：暂停不会释放日志、数据集或输出文件上的锁；
- **权限**：需要与实验进程同一用户权限；管理员权限启动的实验可能暂停失败；
- **长时间暂停**：GPU 驱动、网络连接、外部服务可能超时，恢复后实验自身也可能报错；
- **批量脚本**：如果父 shell 还在继续跑别的任务，暂停只影响这一个实验的进程树。

## 5. 数据文件

`data/paused.json` 示例（字段可能随版本增加）：

```json
{
  "entries": [
    {
      "key": "12345@1700000000.0",
      "pid": 12345,
      "create_time": 1700000000.0,
      "started_at": 1700000000.0,
      "paused_total": 120.0,
      "fingerprint": "d:\\cvpr\\实验|train.py",
      "folder": "D:\\CVPR\\实验",
      "folder_source": "工作目录",
      "title": "train.py",
      "cmdline": "python train.py --epochs 80",
      "exe": "python.exe",
      "paused_at": 1700000120.0
    }
  ]
}
```

该文件只在本机使用，已被 `.gitignore` 排除，不应上传 Git。

## 6. 常见失败

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 暂停失败 / failed 列表非空 | 权限不足、进程已退出、受保护进程 | 用同一用户权限运行小组件；确认实验仍在运行 |
| 继续失败 | 进程在暂停期间被结束或 PID 复用 | 刷新列表；记录会被自动清理 |
| 暂停后实验报网络/超时错误 | 分布式或外部服务超时 | 尽量避免暂停分布式任务；恢复后检查日志 |
| 重启电脑后无法恢复 | 冻结状态只存在内存中 | 无法恢复，只能重新运行；重要实验请用脚本 checkpoint |
| 暂停后仍占显存 | 进程内存/显存未释放 | 这是正常现象，暂停不是释放资源 |
